# Safe-Harbor Note (Scope)

This kit is pure ESP32 firmware helpers + deterministic tests + OpenSCAD + documentation. It contains no cryptocurrency generation, wallet signing, mainnet broadcast, contract deployment, transfer, token authorization, hardware wallet, multisig, or cross-chain logic. No WiFi, Bluetooth, or API calls.

The x402 payment flow is a DOCUMENTATION-ONLY PROTOCOL SPEC (data structures + state transitions). No real wallet signing, Monero transfer, key material, or network call is performed by this kit. The actual payment infrastructure is implemented by the x402 protocol's own systems, not this kit.

Same safe-harbor pattern as #71 eco, #74 agri, #75 DIY, #76 garden, #77 seed, #78 mother, #80 assembly, #81 autoconfig kits.
