# Safe-Harbor Note (S2 boundary)

This kit is pure documentation + pure-JS planning helpers + deterministic jest tests. No cryptocurrency generation, wallet signing, mainnet broadcast, contract deployment, transfer, token authorization, hardware wallet, multisig, or cross-chain logic. No network calls.

## What this kit does NOT do

- No real wallet access or signing
- No mainnet or testnet Monero broadcast
- No real ambassador recruitment -- the pipeline is a state machine for tracking stage progress, not a job-board integration
- No real event registration -- the checklist tracks framework steps, not a venue-booking engine
- No real beta tester onboarding -- the milestone tracker tracks progress, not a hardware dispatch system

## What this kit DOES do

- Provides a structured 6-region hub setup plan
- Scores each proposed hub on agri market, Monero community, and launch readiness
- Builds a phased launch timeline (1-6) so earlier-hub lessons flow to later hubs
- Provides per-region checklists (language, events, farmers, regulations, milestones)
- Models the hub governance (ambassador selection, reporting cadence, milestone structure, funding)
- Tracks the ambassador pipeline (recruiting -> screening -> interview -> onboarded -> active)

## Operator role split

The operator (MyZubster integration team) is responsible for:
- Recruiting and interviewing ambassadors
- Hosting events and booking venues
- Deploying beta test hardware
- Conducting bounty payouts
- Filing local regulatory paperwork

This kit provides the **plan and test harness**; the operator provides the **execution**.
