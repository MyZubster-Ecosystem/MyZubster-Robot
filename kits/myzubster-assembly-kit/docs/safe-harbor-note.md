# Safe-Harbor Note (Scope)

This kit is pure OpenSCAD design + ESP32 firmware helpers + deterministic tests +
documentation. It contains no cryptocurrency generation, wallet signing, mainnet
broadcast, contract deployment, transfer, token authorization, hardware wallet,
multisig, or cross-chain logic. No WiFi, Bluetooth, or API calls. The assembly
line runs entirely offline.

This is the same safe-harbor pattern used by the existing #71 eco kit, #74 agri
kit, #75 DIY kit, #76 garden kit, #77 seed kit, and #78 mother-robot kit in this
repository. The kit is offered as documentation and deterministic firmware logic;
the maintainer can tune station cycle times, conveyor speeds, and quality thresholds
for their specific production setup.
