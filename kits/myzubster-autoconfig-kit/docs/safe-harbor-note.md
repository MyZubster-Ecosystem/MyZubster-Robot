# Safe-Harbor Note (Scope)

This kit is pure ESP32 firmware helpers + deterministic tests + documentation.
It contains no cryptocurrency generation, wallet signing, mainnet broadcast,
contract deployment, transfer, token authorization, hardware wallet, multisig,
or cross-chain logic. No WiFi, Bluetooth, or API calls.

The wallet descriptor is a data structure placeholder with an address string field,
NOT a real Monero wallet. No seed, spend key, view key, or mnemonic is generated.
This is the same safe-harbor type-correction pattern as the accepted #79 DNA kit.

Same safe-harbor pattern as #71 eco, #74 agri, #75 DIY, #76 garden, #77 seed, #78
mother, #80 assembly kits.
