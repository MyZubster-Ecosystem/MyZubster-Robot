# MyZubster Robot Visual Foundation

## MYZ-VIS-015 — Robot Validation Flow

Purpose: explain the repository's prototype-to-validation lifecycle without overstating physical deployment or payment maturity.

Provenance: derived from the current repository README sections `Status`, `Scope`, `Safety`, `Payments and bounties`, and `Contributing`, reviewed 2026-08-23.

Evidence class: `DOCUMENTATION_VISUAL`.

Intended flow: simulation -> bounded hardware integration -> telemetry -> reproducible evidence -> maintainer review. Payment-adjacent experiments remain a separate integration boundary and require independent verification before an external settlement can be represented as final.

Safety boundary: documentation must not imply that self-replication, autonomous purchasing, autonomous settlement, or physical deployment is production-ready without specific implementation and physical validation evidence.

No secrets, private keys, personal data, or claims of real-world deployment are part of this visual package.
