# Bounties — MyZubster Robot

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Robot bounties may cover firmware, simulation, telemetry, safe device integration, APIs, robot identity/data models, documentation and reproducible hardware experiments.

## Evidence

State explicitly whether evidence comes from simulation or physical hardware. Hardware claims require documented test conditions and results.

## Safety

Do not create bounty requirements for uncontrolled actuation, dangerous tools/devices, bypassing safety controls or unauthorized physical testing. Simulation-first is preferred.

## Reward truth

MYZ in the current core platform is an internal reward/accounting ledger. Historical XMR/MYZ bounty labels and merges are not external payment evidence.

## Issues

Use this repository's GitHub issues and link the implementation PR/evidence to the selected bounty.
