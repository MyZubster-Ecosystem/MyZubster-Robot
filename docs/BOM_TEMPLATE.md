## Sourcing policy
1. Prefer manufacturer or authorized distributor for safety/timing-critical parts.
2. Marketplace/search links are convenience paths, not endorsements.
3. Equivalent parts are acceptable only when requirements remain documented.
4. Do not use anonymous/illicit marketplaces for ordinary maker electronics.
5. Archive manufacturer model/datasheet reference, not only a seller listing.

## Purchase acceptance checklist
For every purchased item:
- [ ] exact manufacturer/model recorded;
- [ ] actual paid price and order date recorded;
- [ ] seller/source recorded;
- [ ] datasheet/schematic reference recorded;
- [ ] voltage/current limits checked;
- [ ] mechanical compatibility checked;
- [ ] serial/lot marking recorded when useful;
- [ ] deviations from the reference BOM documented.

## Safety checks before power-on
- [ ] polarity checked;
- [ ] correct logic voltage confirmed;
- [ ] expected current within regulator/driver ratings;
- [ ] protected battery/charger used;
- [ ] physical disconnect available;
- [ ] actuators constrained for first test;
- [ ] no exposed mains-voltage wiring in the reference build.
