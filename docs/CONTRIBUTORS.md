# MyZubster-Robot Contributors

## Digital Identity

All contributors are invited to create a **voluntary MyZubster Digital Identity** linked to their public GitHub alias and verifiable contributions.

### Template

```text
IDENTITY
GitHub alias: @your-handle
Public display name/alias: <optional>
Main contributions: <issue/PR/build links>
Public profile links: <optional>
```

### Example

```text
IDENTITY
GitHub alias: @example-contributor
Public display name/alias: Example Contributor
Main contributions: #123, #456, PR #789
Public profile links: https://github.com/example-contributor
```
